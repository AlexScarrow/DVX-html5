# DVX Windows Pilot - Super Simple Guide

Hi tester. Thank you for helping.
This guide is written to be easy and friendly.

You do **not** need coding skills.
You do **not** need PowerShell just to install and play.

---

## 1) What you will receive

You should get a `.zip` file from WeTransfer.

Inside that zip will be a game folder with:

- one `.exe` file
- some other folders/files next to it

Important:

- Keep all files together
- Do not move only the `.exe` by itself

---

## 2) Install (very easy)

1. Download the zip file.
2. Right-click the zip file.
3. Click **Extract All...**
4. Choose a folder like Desktop.
5. Open the extracted folder.

Now you are ready.

---

## 3) Launch the game

1. Double-click the game `.exe`.
2. If Windows shows a warning:
   - click **More info**
   - click **Run anyway**

This warning can happen with test builds. It is normal for this pilot.

---

## 4) Join a test session

1. Start the game.
2. Go to Multiplayer lobby.
3. Wait for host session to appear.
4. Click the session to join.

If you are hosting instead:

1. Enter lobby.
2. Create host session.
3. Tell the other player when it is visible.

---

## 5) What to test first

Please test this short list:

1. Host can create a session
2. Other player can see and join it
3. Session starts correctly
4. Exit/rejoin once to check stability
5. No freezes, no soft-locks

---

## 6) How to report bugs (simple format)

Copy/paste this and fill it:

```text
What happened:
What I expected:
Can I reproduce it? (yes/no)
How often? (once/sometimes/always)
Screenshot/video: (if available)
Time it happened:
```

Short and clear is perfect.

---

## 7) If something goes wrong

### A) Game will not open

- Make sure you extracted the zip first
- Make sure the `.exe` is still in the same folder as the other files
- Try right-click -> Run as administrator

### B) Cannot see host session

- Confirm both players are using the same test build
- Confirm host is already in the lobby and hosting
- Wait 10-20 seconds and refresh by leaving/re-entering lobby once

### C) Session join blocked by version mismatch warning

This means host and client are on different network versions/builds.
Use the same build file on both PCs.

---

## 8) Quick reassurance

You are not expected to do everything perfectly.
If unsure, just write what you saw and send a screenshot.
That alone is very helpful.

Thank you for testing DVX.
